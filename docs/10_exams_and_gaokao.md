## 二、 学科掌握度与单科上限机制 (Subject Mastery & Cap)

为了杜绝通过后期疯狂刷同一门技能把每代高考都无脑刷到满分的平衡缺陷，系统设计了科学的**单科考分上限与掌握度阶梯**：
- **掌握度折算**：每门课程在日程中排入并执行后，增加该科掌握度（等级 $L = \min(\text{SkillLevel}, 8)$）；
- **考分上限阈值 (`SUBJ_CAP`)**：
  - 语文 (`cn`)：上限 55 点
  - 数学 (`ma`)：上限 60 点
  - 英语 (`en`)：上限 42 点
  - 理科物化生 (`sc`)：上限 58 点
  - 文科政史地 (`so`)：上限 34 点

> **五育并进策略**：单科刷到 Lv8 之后，继续排课将只增长基础属性，无法继续提高单科考分。玩家必须文理兼修、各科均衡并进，才能冲刺全省状元！
>
> **拟真折算 (v3.2.0 收益递减模型)**：掌握度点数按**收益递减曲线**映射到各科卷面分 ($\text{score} = \text{full} \times \frac{p}{p+K}$)：基础分容易拿到，但高分段边际收益递减——全掌握度也只到基础分的 ~60-70%，剩余空间靠属性/考运buff/传家宝/考场发挥填补。满分 750 理论不可达（极限满配 ≈ 705 + 发挥波动），彻底杜绝分数饱和。

## 三、 三大考试算法与升学分流模型

### 3.1 小学期末考试 (Turn 24) —— 满分 300
语/数/英三主科各按收益递减曲线折算 (基础分易得，高分要苦学)，附考场发挥波动 $RI(-12, 8)$：
$\text{Score}_{\text{final}} = \text{clamp}\left(\text{Round}\left(\tfrac{100\,p_{\text{cn}}}{p_{\text{cn}}+4} + \tfrac{100\,p_{\text{ma}}}{p_{\text{ma}}+4.5} + \tfrac{100\,p_{\text{en}}}{p_{\text{en}}+3} + \tfrac{\text{clamp}(iq+mem,\,900)}{10} + \text{Buff} \times 0.8 + RI(-12, 8)\right), 0, 300\right)$
- **排名位次判定**：
  - $< 130$ 分：班级后段 (家庭面子 $-10$)
  - $130 \sim 190$ 分：中游水平 (面子不变)
  - $190 \sim 250$ 分：班级上游 (面子 $+10$)
  - $\ge 250$ 分：名列前茅 (全家喜报，面子 $+20$)

### 3.2 初中中考分流 (Turn 32) —— 满分 700
初升高是当代中国教育的关键分流点。中考成绩直接决定高中档次与高考起步优势 (收益递减折算 + 发挥波动 $RI(-18, 10)$)：
$\text{Score}_{\text{zk}} = \text{clamp}\left(\text{Round}\left(\tfrac{120\,p_{\text{cn}}}{p_{\text{cn}}+9} + \tfrac{120\,p_{\text{ma}}}{p_{\text{ma}}+10} + \tfrac{100\,p_{\text{en}}}{p_{\text{en}}+7} + \tfrac{360\,(p_{\text{sc}}+p_{\text{so}})}{(p_{\text{sc}}+p_{\text{so}})+15} + \tfrac{\text{clamp}(iq+mem,\,900)}{12} + \text{Buff} \times 1.2 + RI(-18, 10)\right), 0, 700\right)$

| 中考总分 | 录取高中学校 | 现实心路与家庭反应 | 面子奖惩 | 赋予高中的高考考分加成 |
|:---:|:---:|:---|:---:|:---:|
| $< 240$ 分 | **职业高中** | “……没事，行行出状元，人生不止高考一条路。” | $-8$ 点 | $+150$ 考分buff |
| $240 \sim 340$ 分 | **普通高中** | “爸妈沉默了一下午，默默给你热了杯牛奶。” | $+5$ 点 | $+300$ 考分buff |
| $\ge 340$ 分 | **省属重点高中** | **全家扬眉吐气！** 单元门前放鞭炮，亲友群红包不断。 | $+20$ 点 | **$+500$ 考分buff (巨大起步优势)** |

### 3.3 高考人生大决战 (Turn 44) —— 满分 750
这是全代养成的终极答卷，与现实高考同构：**语/数/英各满分 150，综合科（理综/文综取并集折算）满分 300**。收益递减折算 + 考场发挥波动 $RI(-25, 10)$：
$$\text{RawScore} = \tfrac{150\,p_{\text{cn}}}{p_{\text{cn}}+15} + \tfrac{150\,p_{\text{ma}}}{p_{\text{ma}}+17} + \tfrac{150\,p_{\text{en}}}{p_{\text{en}}+12} + \tfrac{300\,(p_{\text{sc}}+p_{\text{so}})}{(p_{\text{sc}}+p_{\text{so}})+26} + \tfrac{\text{CAttr}([\text{iq}, \text{mem}], 250)}{18} + \text{Buff} \times 0.9 + \tfrac{\min(\text{img}, 200)}{22}$$
$$\text{GaokaoScore} = \text{clamp}\left(\text{Round}(\text{RawScore} + RI(-25, 10)),\ 0,\ 750\right)$$

> **标定基准 (v3.2.0)**：普通玩家 ≈ 500~650 (一本~985)；全掌握度 + 满属性 + 满buff ≈ 705；满分 750 理论不可达。
>
> **状元特长**：$\ge 690$ 分必定领悟传说特长【状元苗子】(Rank 4，战力 2401)。
