# 34. 班委竞选 3.0 (Class Election 3.0) 经典还原与深度玩法设计

> **对应版本**：v2.9.0+  
> **设计目标**：深度对齐《中国式家长》原版班干部竞选精髓，将小游戏重塑为“三人同台竞选、三大核心指标（师生关系/群众基础/品德表率）、长短板优势劣势克制、五回合动态攻防演说、课桌同学弹幕互动、三档少先队干部任命（三道杠/二道杠/一道杠）”的沉浸式校园博弈舞台！

---

## 一、 核心玩法设计与原版对齐

### 1.1 三人同台鼎立格局 (Three-way Rivalry)
原版班干部竞选的灵魂在于**三位候选人同台争鸣**：
- **我方候选人 (Player)**：根据自身德智体美与日常积累角逐班干部；
- **对手 A · 王小明 (学霸尖子)**：品德表率极高，学习成绩名列前茅，但性格严肃死板，群众基础薄弱；
- **对手 B · 赵小刚 (热血体委 / 捣蛋鬼)**：群众基础极强，仗义请客爱运动，但在老师眼里是不守纪律的刺头，师生关系垫底。

三位候选人争夺全班同学与班主任的整体支持率（从 0% 累积到 100% 相对权重），若某一候选人一马当先，另外两人会本能地发起揭短和围剿，玩家可巧妙借势“坐收渔翁之利”！

### 1.2 三大核心指标与优势/劣势系统
每位候选人（含玩家）在竞选开始时均拥有三大维度评估值与独特的**【优势项】**和**【劣势项】**：
1. **👩‍🏫 师生关系 (Teacher Relation)**：班主任及任课老师的信任与青睐；
2. **👥 群众基础 (Peer Popularity)**：同班同学、前后桌伙伴的人缘与拥戴；
3. **⭐ 品德表率 (Moral Exemplar)**：学习模范、遵守纪律与才艺表率。

- **优势项 (Strength)**：针对优势项发动策略时，不仅基础得分大幅跃升 $+40\%$，且极易触发全班“热烈掌声”！
- **劣势项 (Weakness)**：劣势项上限受限，若强行在劣势项上吹嘘极易翻车被同学嘘声，也是被对手揭短攻击的致命弱点！

玩家的优势与劣势将根据自身当前属性动态测定：
- 情商 $\ge$ 智商 且 情商 $\ge$ 魅力 $\to$ 优势：【师生关系】
- 魅力 $\ge$ 智商 且 魅力 $\ge$ 情商 $\to$ 优势：【群众基础】
- 智商最高 $\to$ 优势：【品德表率】
- 最低的一项属性对应为天生【劣势】。

## 二、 五回合攻防演说策略体系 (5-Round Strategy Matrix)

竞选演说共经历 **5 个回合 (Round 1 ~ 5)**，每回合玩家可从四大动态策略中选择一项行动：

| 策略类别 | 动作名称 | 消耗/门槛 | 作用机制与效果 | 动态台词典故 |
| :--- | :--- | :--- | :--- | :--- |
| **优势宣传** | **📢 自我宣传** | 无 | 针对自身**优势指标**大肆宣传，得票加成 $+40\%$ | “我平时认真听讲、德智体全面发展，选我绝对没错！” |
| **拉拢名师** | **👩‍🏫 亲近老师** | 情商检定 | 帮老师抱作业、整理讲台，强力提升【师生关系】支持度 | “老师您辛苦了！我保证协助班主任抓好班级日常秩序！” |
| **发动群众** | **🍭 亲近群众** | 20元零花钱或魅力检定 | 请吃辣条雪糕或幽默互动，暴涨【群众基础】支持度 | “考完试大家校门口小卖部集合，这周雪糕辣条我包了！” |
| **针对揭短** | **⚡ 揭短抨击** | 针对领先对手劣势 | 曝光对手弱项（如抄作业、偷看漫画），对手支持度暴跌！有概率遭嘘 | “大家别被他骗了！某某昨天还把辣条藏在墨水盒里！” |
| **防守澄清** | **🛡️ 真诚表态** | 遭受攻击后触发 | 化解负面流言，稳固自身阵营并反增同情票 | “清者自清！我只用实际行动和真诚为全班同学服务！” |
| **暗中孤立** | **🤝 联合盟友** | 第 3~4 回合可选 | 联络落后对手共同分化领头羊的群众票仓 | “咱们联手把领头羊拉下来，公平竞争！” |

## 三、 教室全景视觉与互动体验 (Classroom Immersion)

1. **绿底黑板与粉笔字板书**：顶部正中央悬挂少先队队徽，黑板两侧用白色与彩色粉笔书写“班干部民主竞选”与当前轮次倒计时；
2. **讲台三候选人赛马立牌**：玩家与两位对手三足鼎立，顶部直观显示三色支持率进度条、优势/劣势图标徽章与当前实时票数；
3. **课桌同学动态席位**：教室下方错落排列 3 排课桌同学，同学头像随局势动态变化（😊赞同点头、👏鼓掌起哄、🤔抓耳挠腮、😴打瞌睡）；
4. **教室弹幕气泡系统**：每轮发言后，课桌同学头上随机冒出生活化弹幕（“说得好！”、“真的假的啊？”、“我选他我选他！”、“太能吹了吧哈哈哈”）；
5. **音效与打击反馈**：支持粉笔书写声、掌声雷动、嘘声倒彩与胜选欢呼。

## 四、 三档职位任命结算与专属特长荣誉

竞选 5 回合收官后，依据最终支持率排名颁发光荣任命：

### 4.1 🥇 第 1 名：当选【班级中队长 / 班长】
- **荣誉徽章**：光荣佩戴鲜艳“**三道杠**”少先队大队长红臂章！
- **聘书级别**：特等烫金红底正式聘书，盖“中国少年先锋队中队委员会”大红公章！
- **丰厚奖励**：悟性 $+300$、家庭面子 $+100$、父母满意 $+25$、同窗全员好感 $+12$；
- **专属特长称号**：永久解锁金色史诗特长【**威风凛凛一班之长**】（在面子对决中出战威慑全场）。

### 4.2 🥈 第 2 名：当选【副班长 / 宣传委员】
- **荣誉徽章**：佩戴“**二道杠**”红臂章；
- **聘书级别**：银边正式委任状；
- **奖励内容**：悟性 $+180$、家庭面子 $+50$、父母满意 $+15$、全员好感 $+6$；
- **专属特长称号**：解锁稀有特长【**班级得力臂膀**】。

### 4.3 🥉 第 3 名：当选【劳动委员 / 保洁专员】
- **荣誉徽章**：佩戴“**一道杠**”红袖标；
- **聘书级别**：铜边劳动委员光荣任职书；
- **奖励内容**：悟性 $+80$、家庭面子 $+20$、体魄 $+20$、全员好感 $+3$；
- **专属搞笑特长**：解锁搞笑特长【**包干区总管**】（扫地也能扫出自信）。

## 五、 开发规划与里程碑

1. **Round 1 (架构与核心数据)**：编写数据模型、3 人竞争状态机、三大指标计算引擎、AI 对手决策器；
2. **Round 2 (界面与教室舞台)**：构建黑板、讲台立牌、课桌弹幕气泡、三档聘书卡片与键盘支持；
3. **Round 3 (全套测试与回归验证)**：编写专项单元测试套件，验证 3 人机制、胜负判定与全生命周期；
4. **Round 4 (升版发布与更新日志)**：升版至 `v2.9.0`，全渠道同步版本号并推送到 GitHub。
