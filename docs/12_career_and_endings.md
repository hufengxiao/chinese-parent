## 一、 职业判定引擎与五维门槛 (Career Evaluation Engine)

大学毕业与进入社会（Turn 50~57）标志着人生由学生向生产者的转变。
系统不以单一的高考分数定终生（深度致敬原版经典的“7分高考也能当首富”），而是通过**五维心智属性厚度 + 专业技能掌握度**综合核算，在 22 种社会职业分支中自动寻优最具成就感的归宿。

### 1.1 职业匹配度核心算法
系统遍历全部 22 种职业定义，计算角色的属性达标率：
$$\text{Rate}(j) = \frac{\sum_{k \in \text{ReqAttrs}} \text{Clamp}\left(\frac{\text{Attr}(k)}{\text{ReqVal}(k)}, \ 0, \ 1.2\right)}{N_{\text{req}}}$$
- **排序规则**：达标率 $\ge 1.0$ 的职业具备最高优先权；同达标级别下优先选择社会地位更高的阶层（Tier 越大越优先），若仍平局则按达标率数值排序。

## 三、 人生功绩录总评算法 (Grand Life Evaluation)

当第 58 回合结束，系统将开启金光闪耀的**【世代人生功绩录画卷】**，综合考量角色一生的四维成效：

$$\text{TotalLifeScore} = \text{Round}\left(\text{JobScore} \times 0.4 + \text{MarryScore} \times 0.2 + \text{MoneyScore} \times 0.1 + \text{TalentScore} \times 0.3\right)$$

### 3.1 评分细则与评级区间表
- **事业分 ($\text{JobScore}$)**：$\min(100, \ \text{Tier} \times 20 + 20)$
- **婚姻分 ($\text{MarryScore}$)**：校园恋人 100 分；相亲佳缘 85 分；单身立业 40 分
- **财富分 ($\text{MoneyScore}$)**：$\min(100, \ \text{Round}(\text{Money} / 25))$
- **底蕴分 ($\text{TalentScore}$)**：$\min(100, \ \text{AtlasCount} \times 8 + \text{GaokaoBonus})$

## 四、 世代传承交接协议 (Lineage Handoff Protocol)

点击【生下下一代】时，系统触发无缝传承协议：
1. **重置当前代状态**：清空当期回合数、重置学业与压力、重置单代临时技能；
2. **继承祖传底蕴**：
   - 将当前代最终五维属性的 **$18\%$** 全额注入下一代开局属性；
   - 结算并保存下一代开局成长基金（$\text{SeedMoney} = \min(300, \ \text{Money} \times 0.15)$）；
   - 更新下一代家族门第阶层（$\text{FamTier} = \max(\text{PrevTier}, \ \text{JobTier})$）；
   - 激活家族特长每回合自然成长点数（$\text{PerTurnGrowth} = \max(1, \ \lfloor \text{AtlasCount} / 2 \rfloor)$）；
3. **世代编号累加**：$G = G + 1$，生成下一代崭新生命，开启充满希望的全新世代！
