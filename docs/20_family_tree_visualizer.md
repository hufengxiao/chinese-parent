# 20. 百年家族族谱树状画卷可视化设计 (Family Tree Visualizer)

> 对应进阶路线：Round 6 (TREE-VIS) 世代传承与自豪感升华

---

## 一、 系统痛点与设计宗旨

- **痛点**：目前图鉴中的【家族史】采用垂直平铺文本卡片，缺乏家族宗族脉络的开枝散叶之感，玩家难以一览数百年家族从“寒门贫农”一步步攀登至“书香望族”的宏伟史诗感；
- **目标**：打造纵深式国风树状代际脉络图谱，以青墨枝干连接每一代先祖，展示生平官职、配偶贡献、高考状元印章与家族贡献度。

---

## 二、 树状画卷结构设计

### 2.1 宗族总览牌匾 (Ancestral Hall Banner)
族谱顶部设立金色家族牌匾：
- **宗族世系**：已绵延 $N$ 代；
- **家族底蕴**：世代收录特长总数、成就荣誉数；
- **先天天赋庇佑**：累计注入的五维基因传承点；
- **最高门第**：寒门 / 平民 / 中产 / 书香 / 巨贾 / 望族。

### 2.2 世代节点卡片 (Genealogy Node Card)
每个世代卡片包含以下视觉层级：
1. **先祖立绘与印章**：代数水墨印（如：`第 1 代始祖`、`第 3 代宗亲`）；
2. **生平最高功业**：职业图章（如 `💼 互联网集团合伙人`、`🎓 清华大学状元`）；
3. **联姻配偶信息**：展示伴侣名称、头像与配偶为家族基因库带来的先天天赋加成；
4. **终局总评分**：S/A/B 级评级金印。

### 2.3 墨线脉络与平滑交互
- 节点之间采用 CSS 伪元素与矢量贝塞尔曲线连线，形成生生不息的宗族根脉；
- 支持左右横向与纵向平滑滚动，适应长达数十代的深度谱系。
