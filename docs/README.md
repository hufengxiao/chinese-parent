## 🎯 核心设计哲学

1. **原汁原味的心流复刻**：
   以原版《中国式家长》为标杆，严格再现“挖脑洞攒悟性 ➔ 属性打折研习新课程 ➔ 安排六件事兼顾压力与满意度 ➔ 考试升学与特长对决 ➔ 高考定乾坤 ➔ 选专业成家立业 ➔ 把希望传给下一代”的心流闭环。
2. **零依赖与极致轻量**：
   抛弃沉重的打包工具、重型前端框架与后端服务器，坚持原生纯 HTML5 + CSS3 + 现代原生 JavaScript，数据持久化保存在浏览器本地，实现“秒开、轻快、永不丢档”。
3. **真实幽默的文化共鸣**：
   以戏谑幽默而又充满温情的笔触，提炼中国式家庭教育、校园生活与职场人生的真实细节，让玩家在会心一笑中体会家庭传承的沉淀与厚重。
