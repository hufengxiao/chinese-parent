## 一、 悟性研习与属性折扣机制

在《中国式家长》中，**“悟性”是开启知识大门的钥匙，而“属性”则是降低求知阻力的阶梯**。
如果你本身数学逻辑（智商）极高，学习高等代数如同顺水推舟，只需耗费极微量悟性；反之若属性不足强行越级研习，则需要砸入天量悟性。

### 1.1 研习成本动态折算公式
每门课程的悟性研习标价遵循如下公式：
$$\text{Cost}(c) = \max\left(5, \ \text{Round}\left(\text{BaseInsight}(c) \times (1 - \text{Discount})\right)\right)$$

其中：
- **阶段基础研习底价 ($\text{BaseInsight}$)**：
  - 婴儿期 (`baby`)：20 点
  - 幼儿园 (`kinder`)：35 点
  - 小学期 (`pri`)：55 点
  - 初中期 (`junior`)：85 点
  - 高中期 (`senior`)：130 点
  - 大学期 (`college`)：160 点
- **对应主属性折扣系数 ($\text{Discount}$)**：
  $$\text{Discount} = \text{Clamp}(\text{AttrVal}(\text{MainAttr}) \times 0.003, \ 0, \ 0.75)$$
  *例如：当角色智商达到 250 点时，研习数学、物理与编程课程可享受满额 $75\%$（两五折）的超级折让，最高可将 130 悟性降至 33 点！*

## 二、 九大学科课程体系与能力谱系 (51门全景课程)

课程体系覆盖德智体美劳与社会通识，横跨 8 大人生阶段：

```
学科大类 ──────┬── 语文系 (语言理解、名著、抒情写作) ─── [情商 / 记忆 / 想象]
              ├── 数学系 (四则、代数、函数、奥数) ─────── [智商 / 逻辑]
              ├── 英语系 (单词、音标、语法、听力) ─────── [记忆 / 情商]
              ├── 理科系 (常识、物理、化学、生物) ─────── [智商 / 记忆]
              ├── 文科系 (历史演进、地理版图、政治) ───── [记忆 / 情商 / 想象]
              ├── 体育系 (体能锻炼、耐力跑、中考冲刺) ─── [体魄]
              ├── 艺术系 (涂鸦、橡皮泥、电子琴、美术) ─── [想象 / 魅力]
              └── 编程系 (电脑入门、算法、全栈架构) ───── [智商 / 想象]
```

## 三、 特长稀有度与“7的倍数”战力体系 (Talents & Combat Power)

特长是孩子在日常研习与兴趣玩乐中沉淀下来的“高光技能”，不仅是日常荣誉的象征，更是**面子对决（战斗）与特长选秀（牌面博弈）中的终极武器**。

遵循原版严谨的数值几何倍增模型，特长攻击力严格遵循 **“7 的次方”** 经典公式：

$$\text{Atk}(\text{Rank}) = 7^{\text{Rank}}$$

| 稀有度档位 | 中文称谓 | 标识颜色 | 战力攻击点数 | 典型特长代表 | 解锁源头与条件 |
|:---:|:---:|:---:|:---:|:---|:---|
| **Rank 1** | **普通特长** | 灰白色 | **7 点** | 【顺风翻身】、【涂鸦小能手】、【拼词快刀】 | 基础幼儿动作、涂鸦、拼音等初级技能 |
| **Rank 2** | **稀有特长** | 碧绿色 | **49 点** | 【琴童出征】、【江湖百晓生】、【行走的诗词库】 | 电子琴、古诗词背诵、武侠小说阅读 |
| **Rank 3** | **史诗特长** | 紫晶色 | **343 点** | 【键盘钢琴家】、【小作文战神】、【力学狂人】 | 深入学习各学科进阶、索取高阶心愿乐器 |
| **Rank 4** | **传说特长** | 耀金色 | **2401 点** | 【指尖琴魔】、【奥数霸王龙】、【代码破壁人】 | 达成九级巅峰课程、满分高考状元专属 |

### 特长领悟机制：
- 当玩家将课程排入日程并执行结算时，若该课程配置有 `tal: { id, p }`，系统将以概率 $p$ 触发顿悟判定；
- 领悟成功后，屏幕亮起金光弹窗，该特长永久收入个人技能库，并**即时刻入《家族特长图鉴》**。

## 四、 世代特长图鉴 (Family Atlas)

1. **永不磨灭的家族遗产**：图鉴跨越世代存档存储在 `cph_fam` 中。即使某一代表现平平甚至遗憾崩溃，已收录的特长永不遗失。
2. **家族天赋正向反哺**：图鉴累计收集的特长越多，下一代开局的自发成长点数越高，形成了“后代踩在先祖肩膀上登顶”的长线代际成长心流。
