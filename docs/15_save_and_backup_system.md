# 15. 存档管理与跨设备数据迁移系统设计 (Save Management & Backup System)

> 对应进阶路线：Round 1 (ARCH-SAVE) 核心数据底座

---

## 一、 系统背景与设计宗旨

在原本的单页单存档架构中，所有状态均依托浏览器本地唯一的 `localStorage` 键值（`cph_save` 与 `cph_fam`）。这一机制在长期游玩中存在三大核心痛点：
1. **防丢能力脆弱**：玩家无意清理浏览器缓存、在隐私/无痕模式下滑动误关闭页面，往往导致历经十几代的百年家族谱系瞬间蒸发；
2. **跨设备迁移壁垒**：玩家在电脑浏览器与手机端之间无法自由同步，难以在通勤途中延续 PC 端的高考进度；
3. **多路线探索受限**：玩家只能在一条人生线路上走到黑，无法同时开辟“满门清北学术流”与“白手起家商界流”。

本系统旨在建立**多槽位独立隔离**、**秒级文本码复制/恢复**与**离线 JSON 文件安全备份**的三维数据保障体系。

---

## 二、 数据结构与存储协议规范

### 2.1 槽位划分与键名规范
系统提供 3 个彼此完全隔离的物理槽位（Slot 0、Slot 1、Slot 2）：

| 存储键名 | 数据类型 | 描述说明 | 默认值 |
|:---|:---|:---|:---|
| `cph_active_slot` | `String` (`'0'/'1'/'2'`) | 当前正在游玩的活动槽位指针 | `'0'` |
| `cph_save_{N}` | `JSON String` | 槽位 N 的单局核心状态数据（`S` 对象） | `null` |
| `cph_fam_{N}` | `JSON String` | 槽位 N 的家族世代谱系、特长图鉴与成就荣誉 | `null` |

### 2.2 导出备份数据包格式 (Backup Payload)
导出的文本码采用标准 JSON 封装并通过 Base64 编码，并包含完整性 Magic 标识与摘要校验信息：

```json
{
  "magic": "CPH_SAVE_PACKAGE",
  "ver": 2,
  "exportAt": "2026-09-29T10:35:00.000Z",
  "slotIndex": 0,
  "summary": {
    "gen": 3,
    "name": "小龙",
    "gender": "boy",
    "turn": 28,
    "phase": "junior",
    "score": 8200,
    "familyGenerations": 2,
    "familyTalentsCount": 16,
    "achievementsCount": 6
  },
  "save": { ... },
  "fam": { ... },
  "checksum": "a7f8e9..."
}
```

## 三、 核心状态机 API 与迁移机制

### 3.1 老玩家存档平滑升迁 (Zero-Loss Migration)
初始化加载时，若发现旧键 `cph_save` 或 `cph_fam` 存在，且 `cph_save_0` 尚未创建，系统自动执行静默迁移：
```javascript
if (LS.getItem('cph_save') && !LS.getItem('cph_save_0')) {
  LS.setItem('cph_save_0', LS.getItem('cph_save'));
  if (LS.getItem('cph_fam')) {
    LS.setItem('cph_fam_0', LS.getItem('cph_fam'));
  }
  LS.setItem('cph_active_slot', '0');
}
```

### 3.2 槽位控制接口 (`window.CP.saveManager`)
1. **`listSlots()`**: 扫描并返回 3 个槽位的元数据数组（是否为空、代数、姓名、阶段、回合、保存时间、特长数等）；
2. **`switchSlot(idx)`**: 切换活动槽位并立即载入对应状态，触发页面全量渲染；
3. **`exportSlot(idx)`**: 生成并返回指定槽位的标准 Base64 文本码及 JSON 字符串；
4. **`importSlot(rawText, targetIdx)`**: 校验文本有效性，防御恶意注入或损坏数据，成功后写入目标槽位并自动提示恢复结果；
5. **`clearSlot(idx)`**: 安全清空指定槽位（需二次确认）。

## 四、 UI/UX 交互与操作流

1. **常驻入口**：顶栏系统快捷区增加 `💾 存档` 按钮；
2. **家族记忆录弹窗**：采用典雅国风宣纸卡片并排展示 3 个槽位：
   - 正在游玩的槽位高亮展示，带【进行中】金色徽章；
   - 空槽位显示【虚位以待】水墨框，支持一键点击【开启全新世代】或【导入外部存档】；
3. **备份与导入流**：
   - 【📋 复制备份码】：一键写入系统剪贴板，手机微信/QQ 发送电脑即可无缝粘贴导入；
   - 【💾 下载存档】：直接触发浏览器生成 `中国式家长_第X代_存档.json` 文件下载；
   - 【📥 导入存档】：提供多行文本框粘贴与本地文件选择器，自动预检并展示备份摘要（如：*“检测到有效存档：第4代·小美 (高中)，是否确认载入槽位 2？”*）。

## 五、 质量保障与自动化测试用例

1. **测试用例 1 (升迁)**：模拟只有旧版 `cph_save` 的老用户环境，验证启动后槽位 0 自动拥有该存档且游玩不中断；
2. **测试用例 2 (隔离)**：槽位 0 和槽位 1 分别推进至不同回合，验证切换后五维属性、特长、行动力互不串扰；
3. **测试用例 3 (还原)**：槽位 0 导出为 Base64 编码，导入至槽位 2，断言所有核心字段深拷贝等价；
4. **测试用例 4 (容错)**：传入非 Base64 杂乱文本、缺少 Magic 头或字段缺失的损坏数据，验证系统优雅报错且原存档不被覆盖。
