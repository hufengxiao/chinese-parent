## 一、 界面视口规范与响应式布局

游戏采用**移动端竖屏优先（Mobile-First Portrait）**设计基准。
- **核心基准视口**：以 $375\text{px} \sim 430\text{px}$ 宽度为基准布局（完美适配 iPhone、各类主流 Android 竖屏旗舰）；
- **宽屏与桌面自适应**：在 iPad、笔记本与桌面浏览器中，外层容器自动限制最大宽度为 $480\text{px}$ 并水平居中，四周搭配优雅的磨砂阴影背景，既保证沉浸感，又避免宽屏下元素拉伸失真；
- **全面屏适配**：支持 iOS Safari 与 Android 状态栏的 `viewport-fit=cover` 与安全区（Safe-Area Insets）适配。

## 二、 交互微创新亮点机制

### 2.1 Toast 轻提示单次消费与独立生命周期
为了彻底解决同类文字养成游戏中“旧提示反复堆叠遮挡顶部信息”的顽疾，UI 引擎引入了**提示队列的单次动态消费模型 (`flushToasts`)**：
- **单次提取清空**：一旦提取并渲染为 DOM，内存队列立即清空；后续任何点击不会重复唤醒历史废弃消息；
- **独立淡出生命周期**：每条 Toast 拥有独立的 $2.5\text{s}$ 计时器，到期后执行 CSS Keyframes 平滑上浮淡出；
- **点击快速关闭**：玩家急需查看顶栏数值时，点击任意一条 Toast 即可立即将其移除，交互极致丝滑。

### 2.2 新手聚光灯遮罩引导 (Spotlight Walkthrough)
针对初次进入游戏的新玩家，系统提供了基于高亮遮罩的 **5 步趣味交互教学**：
1. **启幕问候**：介绍游戏目标与中国式家庭养成背景；
2. **聚光脑洞**：引导玩家点击脑洞 Tab，翻开人生第一格潜能；
3. **悟性研习**：教学如何使用挖出的悟性点亮新技能；
4. **排满日程**：指导 6 槽位劳逸平衡原则与一键智能排满功能；
5. **常驻备忘录**：点击顶栏右上角 📖 图标，随时可唤出《通关备忘录》查阅全科目成长秘籍。

## 三、 WebAudio 纯原生无依赖音效合成引擎 (Sound Synthesizer)

游戏完全摒弃了体积庞大、加载迟缓的外部 MP3 音频文件，完全基于浏览器原生底层 **Web Audio API (`AudioContext`)**，通过纯数学正弦波、三角波与锯齿波振荡器实时运算合成声音：

| 音效名称 | 触发情境 | 声学合成参数与波形算法 | 听觉心理感受 |
|:---|:---|:---|:---|
| **`click`** | 常规按钮点击、Tab 切换 | $600\text{Hz}$ 正弦波 (`sine`)，持续 $0.04\text{s}$，指数衰减 | 极其轻盈利落的触控反馈 |
| **`pop`** | 排入日程槽位、选择选项 | $850\text{Hz}$ 三角波 (`triangle`)，持续 $0.06\text{s}$ | 类似气泡爆破的清脆回弹感 |
| **`coin`** | 获得零钱、商店购买成功 | 双音正弦和弦：先 $987\text{Hz}$ 延时 $60\text{ms}$ 接入 $1318\text{Hz}$ | 叮咚作响的金币入袋喜悦 |
| **`brain`** | 翻开脑洞节点 | 双音递进：$520\text{Hz} \rightarrow 1040\text{Hz}$，八度跳跃 | 灵感闪现与脑突触觉醒感 |
| **`win`** | 特长选秀夺冠、对决大胜 | 四音胜利上行琶音：$[523, 659, 783, 1046]\text{Hz}$ (C-E-G-C) 三角波 | 欢欣鼓舞的凯旋号角 |
| **`fail`** | 对决惜败、期末考砸 | 三音下行降调音阶：$[400, 340, 280]\text{Hz}$ 锯齿波 (`sawtooth`) | 略带遗憾但滑稽可爱的低落音 |

- **静音记忆**：顶栏 🔊 图标一键静音，状态永久保存在 `localStorage.cph_mute` 中，尊重各种安静场景下的摸鱼体验。

## 四、 本地持久化与断电保护机制 (LocalStorage Architecture)

整个游戏的状态持久化分为两层，完全由原生 JSON 序列化管理：
1. **单代即时运行档 (`cph_save`)**：
   - 包含当前回合数、6 槽位、当前六维属性、已掌握技能树、当前层脑洞矩阵、待处理事件队列；
   - **每一步关键交互后（点击脑洞、研习技能、安排日程、解决事件）即刻自动调用 `persist()` 同步落盘**；
   - 手机浏览器误触后退、意外刷新或系统杀进程，重开后一秒无缝续玩。
2. **家族万世家谱档 (`cph_fam`)**：
   - 独立持久化存储家族世代数 $G$、最高门第 Tier、累计特长图鉴全集 Atlas、历代先祖成就碑文与遗传基因；
   - 即使手动重置某代角色的进程，亦可自主选择保留祖传家谱底蕴。
