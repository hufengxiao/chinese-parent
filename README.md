## 📖 项目简介 (Overview)

《中国式家长 H5》是一款使用**纯原生前端技术栈（Vanilla HTML5 / CSS3 / ES6+ JavaScript）**深度还原经典模拟养成游戏《中国式家长》核心玩法的开源网页游戏。

你将出生在一个普通的中国家庭，从婴儿期的抓周与幼年动作开始，历经幼儿园、小学、初中、高中、大学到步入社会成家立业的完整人生闭环：
- 👪 **家庭育儿风格流派**：虎妈狼爸、佛系放养、精英鸡娃、民主伙伴四大特色流派与专属特权阻力；
- 🧠 **脑洞 2.0 突触连锁**：同色邻接连击倍率、潜意识外溢翻格与高维顿悟行动点返还；
- 🏺 **传家宝与祖宅百宝阁**：8 大稀世传家宝物，百宝阁双槽位佩戴，世代永续词条加成；
- 👥 **同窗校友人脉网络**：昔日同窗成年后蜕变各界行业精英，提供学术、医疗、金融、政务全方位资源倾斜；
- 🎓 **大学四向深造岔路**：学术深造、政界公职、创业风投、名企骨干四向深度分支与四大巅峰终局成就；
- ⚔️ **全系小游戏 2.0 重塑**：过年红包物理推拉、面子对决特长手牌与破防石化、才艺选秀节拍演播与三大阵营班干部竞选；
- 📜 **百年家族谱系画卷**：娶妻生子，将先天天赋、职业成就与门第基因世代相传，培育百年望族！

## ✨ 核心特色与系统全览 (Key Features)

### 1. ⚔️ 原汁原味 · 面子对决原版经典深度还原 (Faithful Face Duel · v2.8)
- **五大人生经典亲戚对决**：对齐原版成长轨迹，幼小初高五大阶段迎战远房表嫂（早教优越）、二姨（才艺培训）、二舅妈（学科奥数）、周阿姨（综合素质）、大姑（名校保送）；
- **特长单场单次消耗制 (Single-Use Protocol)**：深度复刻原版策略核心！每项掌握的特长单场仅可出战 1 次，出战后变灰锁定并加盖【已出战】印章，考验平时特长深度积累与出招次序；
- **特长品阶专属原版特效**：
  - **Rank 1 普通**：基础稳定输出（18~28 点）；
  - **Rank 2 稀有**：35% 几率触发【精彩暴击！】（1.5 倍伤害并大量增加对手破防槽）；
  - **Rank 3 史诗**：必定附加【气焰受挫】（造成高额伤害并削弱对手下轮攻击 40%）；
  - **Rank 4 传说**：必定触发【传说降维打击！】（真伤破防贯穿全场）；
- **特长耗尽保底【客套赔笑】**：所有特长用尽时提供专属中国式人情世故保底招式，勉强应对不卡死；
- **现场对峙气泡与老妈必杀**：实时渲染亲戚炫耀挑衅与老妈犀利回怼台词气泡；老妈怒气满 100% 触发拍案而起全家杀手锏；
- **面子与索取成长飞轮**：赢下面子对决大幅提升家庭面子，解锁向父母索取高阶器材（橡皮泥、电子琴、黄冈密卷），解锁高阶特长碾压下一轮对决！

### 2. 👪 家庭育儿风格流派系统 (Parenting Styles · v2.7)
- **四大特色流派**：每代出生时根据前代声望与门第智能抽选流派：
  - **🐯 虎妈狼爸**：学习类行动消耗仅需 2 点行动力，严禁索取娱乐心愿；
  - **🧘 佛系放养**：每回合自然减压 -8 点，心理阴影爆发阈值永久截断在 60 点；
  - **🦅 精英鸡娃**：面子对决伤害大幅提升 25%，但在对决中落败会额外扣除 25 点满意度；
  - **🤝 民主伙伴**：父母满意度享有 50 点硬底保底，索取心愿失败无任何负面惩罚；
- **UI 动态感知**：顶栏元信息区实时展示流派徽章，悬停即刻查阅流派专属特权与家庭阻力。

### 2. 🏺 传家宝与祖宅百宝阁系统 (Ancestral Relics & Heirlooms · v2.7)
- **祖宅百宝阁**：在【图鉴】中开辟独立「百宝阁」抽屉，世代陈列传承积累的稀世珍宝；
- **8 大传家宝物**：老式二八大杠（+10⚡/回）、首届高考准考证（高考+350分）、深圳老八股认购证（工薪+40%）、红双喜球拍（面子对决40%反弹）、海鸥双反相机（选秀全绿灯）、褪色红领巾（竞选票数+30%）、紫砂老茶壶（-10压力/回且减半阴影）、定情手织毛线围巾（相亲100%成功且面子翻倍）；
- **双槽位配装保护**：严控数值跨代通胀，设定严格的双槽位佩戴限制，自由切换出战宝物。

### 3. 👥 同窗校友圈与成人期人脉网络 (Alumni Network · v2.7)
- **成人期精英羁绊**：告别“高中毕业即失联”，昔日同窗在大学期、职场期与成家立业期升级为行业栋梁：
  - **王胜男（体育大学副教授）**：国家队级体能特训（体魄 +150）；
  - **苏夏（文联特聘作家）**：名刊撰稿背书与学术辅导（智商 +120，情商 +60）；
  - **林秋石（中关村资深架构师）**：攻坚技术底层架构（智商 +150，返还 5 ⚡）；
  - **秦小梅（三甲医院主治医师）**：心理疏导与健康管理（压力归零，满意度 +30）；
  - **朱小文（市工商业联合会理事）**：商业圈层资源引荐（情商 +180，面子 +40）；
  - **周美美（顶级红圈所合伙人）**：公关事务与名誉塑造（面子 +80，零钱 +100）；

- **每回合限次求助**：在成年期【同学】面板中直接呼叫援助，消耗零花钱换取决定性助力。

### 4. 🧠 脑洞 2.0 神经突触连锁共鸣 (Synaptic Combos 2.0 · v2.7)
- **4 连通同色连锁算法**：翻开任意脑洞节点时，BFS 邻接扫描上下左右同色属性球计算连击；
- **阶梯倍率与潜意识外溢**：
  - **2 连击**：属性获得基础倍率 `x1.25`；

- **脑洞 HUD 视效联动**：连击浮标实时霓虹跳出，单元格触发金色流光呼吸脉冲。

## 🛠️ 本地运行与开发 (Local Development)

本项目为**纯静态项目，零第三方打包编译流程**，开箱即用：

```bash
# 1. 快速克隆
git clone https://github.com/hufengxiao/chinese-parent.git
cd chinese-parent

# 2. 启动本地预览服务 (推荐)
npm start

# 或使用 Python 内置服务: python -m http.server 8080
# 或直接在浏览器中双击打开 index.html
```

## 🧪 自动化测试套件 (Automated Headless Testing)

项目构建了严密的无头（Headless）自动化测试体系，覆盖核心数值闭环、参数越界防御、多代连续遗传仿真与 UI 边界断言：

```bash
# 运行全量 7 大测试套件
npm test
```

### 独立测试命令：
- **`npm run test:election`**：运行 [`tests/test_class_election_faithful.js`](./tests/test_class_election_faithful.js)，专门验证班委竞选 3.0 三大候选人同台模型、师生/群众/品德核心指标与长短板测定、5 回合策略攻防揭短、课桌同学动态漫画气泡、三档职位任命（三道杠/二道杠/一道杠）与专属特长赋予；
- **`npm run test:duel`**：运行 [`tests/test_face_duel_faithful.js`](./tests/test_face_duel_faithful.js)，专门验证面子对决 3.0 街机格斗、五大亲戚对峙台词、特长单次消耗出战、品质暴击削弱真实伤害与老妈怒气必杀；
- **`npm run test:v27`**：运行 [`tests/test_v27_features.js`](./tests/test_v27_features.js)，验证 v2.7.0 全部五大核心玩法（育儿流派被动、祖宅百宝阁双槽位、校友成人羁绊、脑洞2.0连锁BFS与倍率、大学四向分流与职业成就），并执行 **10 代全随机混沌策略无头沙箱压力测试**！
- **`npm run test:gameplay`**：运行 [`tests/test_new_gameplay.js`](./tests/test_new_gameplay.js)，验证包含小游戏2.0重塑、红包推拉、面子对决手牌、选秀Showtime、班干部选民阵营、**20 代全随机混沌策略生命周期压力测试**、新版本公告自愈弹窗、双层顶栏防遮挡、多存档槽位管理等全部 **28 项核心机制**；
