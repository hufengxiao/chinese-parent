## 📖 项目简介 (Overview)

《中国式家长 H5》是一款使用**纯原生前端技术栈（Vanilla HTML5 / CSS3 / ES6+ JavaScript）**深度还原经典模拟养成游戏《中国式家长》核心玩法的开源网页游戏。

你将出生在一个普通的中国家庭，从婴儿期的翻身与抓周开始，历经幼儿园、小学、初中、高中、大学到步入社会成家立业的完整人生闭环：
- 🧠 **脑洞突触探索**：翻开灵感迷雾矩阵，点亮智慧灯泡与五维属性；
- 📅 **日程张弛有度**：在海量课程与课外娱乐中权衡，平衡父母满意度与心理阴影防线；
- ⚔️ **经典社会交锋**：亲戚面子对决凡尔赛、大年三十红包推拉拉扯、特长选秀三评委亮灯、班干部多轮竞选拉票；
- 🎓 **高考大关与职场跃迁**：全科掌握度折算两万满分标化分，填报高校志愿，进阶职场答辩与晋升；
- 📜 **百年家族谱系**：娶妻生子，将先天天赋、职业成就与门第基因世代相传，培育百年望族！

## ✨ 核心特色与系统全览 (Key Features)

### 1. 🧠 脑洞探索系统 (Brain Cave Minigame)
- **6×6 灵感迷雾矩阵**：每回合重置 36 节点迷雾神经网；
- **多元奇遇节点**：💡 悟性灯泡、🎨 单属性球、⚡ 行动力闪电、💀 脑内风暴（全五维提升）、💰 零花钱罐、🦆 呆萌鸭子；
- **💥 九宫格连锁爆破与震屏**：挖出炸弹触发真实贝塞尔曲线物理震颤动效，瞬间连环翻开周边 8 格；
- **🗝️ 钥匙现世聚焦与两段式下潜 (v2.4)**：挖出钥匙（直挖或炸弹波及）后盘面绝不立即跳变！钥匙格子保留显示并进入金色呼吸脉冲锁定状态，点击高亮钥匙才正式开启通道下潜（单次回顾 $+50$ 点大额体力补给与更丰硕收益加成），拒绝误触与跳闪！

### 2. 📅 顶部属性动态浮标与日程知识树 (Attributes & Schedule)
- **✨ 顶部属性与资源增长动态浮标 (v2.4)**：引入属性变动 Diff 引擎，六维属性与四大核心资源增长时，卡片上方冒出翠绿/金色 `+N` 渐隐浮动徽章并伴随温和呼吸脉冲光效（`scale(1.08)`），成长一目了然！
- **50+ 门全阶段课程**：涵盖语数英、物化生、政史地、音美体与编程奥数；
- **德智体美劳五维属性**：智商（`iq`）、情商（`eq`）、记忆（`mem`）、想象（`img`）、体魄（`phy`）、魅力（`cha`）；
- **动态心理生命线**：
  - **父母满意度**：排课学习增加满意度，$\ge 80\%$ 获赠大件心愿索取机会；$<15\%$ 触发连夜训斥；
  - **压力值与心理阴影**：高强度学习累积压力，压力超 $100\%$ 永久转化为**心理阴影**，满额触发精神崩溃 BE 结局；
- **高效排程**：支持一键“⚡ 自动排满”与“🧹 一键清空”，智能劳逸结合防崩溃。

### 3. 🌟 特长才艺选秀大会 (The Talent Show)
- **四大成长阶段固定登台**：幼儿园初啼、小学兴趣博览秀、初中青春汇演、高中终极盛典；
- **三大性格评委亮灯**：张教授 🧐、麦克老师 🕶️、李主任 👩‍🏫 实时举牌打分（`💡 亮灯通过` / `❌ 灭灯`）；
- **天量悟性大奖**：根据特长战力（$7^{\text{Rank}}$）判定胜负，夺冠斩获高达 500 点悟性大奖与丰厚面子。

### 4. 🗳️ 班干部三向竞选演说 (Class Committee Election)
- **讲台即时红蓝选票看台**：直面竞争对手，争夺全班 50 票中的过半任命门槛（26票）；
- **四大经典拉票策略**：亲民路线（情商加成）、才艺展示（特长加成）、零食许诺（金钱公关）、严密施政（智商加成）；
- **胜选任命公报**：夺取班级中队长职务，全班好感度飙升，家庭面子大幅增长。

### 5. 🧧 过年收红包动态推拉 (Red Packet Tug-of-War)
- **客套拉扯微妙博弈**：“使不得”与“真不要”之间的动态拉锯战；
- **黄金平衡区间**：精准掌控指针停在得体平衡区，赢得双倍压岁钱与亲友赞叹，推脱过猛或急切贪婪均会触发戏剧性恶搞结局。

### 6. ⚔️ 亲友面子回合制大对决 (Face Duel)
- **亲戚凡尔赛大对决**：迎战隔壁学霸小明、有钱叔叔、刘婶孙女等各路强敌；
- **回合制出招博弈**：客套反弹借力打力、轻描淡写凡尔赛刺痛对手、亮出高阶特长绝技绝杀对手心理防线。

### 7. 👥 同学社交背包定向送礼 (Social & Romance)
- **10 位性格各异同窗好友**：苏软软、沈寒、夏小美、王小明、林风等；
- **专属喜好暴击台词**：针对同窗喜好定向赠送小卖部礼物（奶茶、手账、磁带、篮球），好感度暴击飙升；
- **浪漫毕业求婚**：高考毕业后解锁同窗专属回忆立绘相册与深情告白，相约携手步入婚姻殿堂。

### 8. 🎁 独立向父母索取心愿面板 (The Begging Shelf)
- **大件心愿独立货架**：全套漫画大全、小霸王游戏机、名牌气垫跑鞋、真木立式大钢琴、黄冈密卷；
- **面子与满意度门槛**：自由预览索取成功率与永久属性加成，零机会下安全查阅不卡死。

### 9. 🎓 高考志愿梯度填报 (Gaokao & College)
- **两万分标化考分模型**：各科掌握度与属性深度挂钩，杜绝后期刷分无脑膨胀；
- **高校梯度填报**：清北名门、985学府、211重点、统招一本、普通二本、专科职高；
- **对口技能解锁**：根据录取院校专业解锁大学期专属技能研习（计算机软工、临床医学、金融管理等）。

### 10. 💼 职场期年中绩效考核与晋升答辩 (Career Promotion)
- **职场专属工作与摸鱼日程**：💻 赶项目、☕ 带薪摸鱼、📜 考专业证书、🍷 高端商务宴请；
- **集团年中考评答辩**：技术硬实力、团队领导力、敬业执行力三大攻坚答辩策略；
- **职级进阶与薪水倍增**：斩获 S+ 评级直接擢升资深/主管/总监/合伙人，月薪暴涨，父母欣慰之至。

### 11. 📜 百年氏族树状族谱画卷 (Lineage Tree Visualizer)
- **青墨纵深世系画卷**：开基始祖与历代先祖采用纵深代际墨线相连，生平功绩卡片一目了然；
- **先祖荣耀金牌与徽章**：根据高考、职级与生平赋予 `👑 开基始祖`、`📜 宗亲` 勋印与名校殿堂高光；
- **当代在世苗裔联动**：当代主角作为枝头青翠幼苗联动生平书写状态，传承四项先祖总谱核心底蕴。

### 12. 👥 同学五阶双向羁绊与毕业信物 (Social Bonds & Graduation Token)
- **五阶羁绊进阶体系**：点头之交、同窗好友、志趣相投、莫逆之交，好感突破 100 封顶达 150 青梅竹马；
- **突发放学邀约大事件**：初高中阶段随机触发密友周末约会与课外漫步大事件，多重互动抉择；
- **高三终局毕业纪念信物**：高考前夕与至交密友互赠绝版纪念信物，永久载入生平并大幅提升属性。

### 13. 🎵 原生 WebAudio 中国风五声 BGM (Procedural Pentatonic BGM)
- **宫商角徵羽音律算法**：纯原生 WebAudio 实时程序化合成，无需下载任何外部音频文件，极速秒开；
- **三态音频状态机**：支持 `静音 (Muted)` / `仅音效 (FX Only)` / `音效与BGM (All Sound)` 平滑切换与无感兼容；
- **高潮音效群**：高考揭榜、才艺选秀评委亮灯、终身大事求婚誓言专属程序化高潮激昂旋律。

### 14. 💾 独立多存档槽位管理与跨端迁移 (Multi-Save Slot System)
- **3 独立存档槽位**：支持随时在槽位 1、槽位 2、槽位 3 自由切换，属性与家族树完全隔离独立推演；
- **跨设备一键复制**：一键生成与粘贴 Base64 存档码，支持跨电脑、手机与平台瞬间迁移无缝接关；
- **离线 JSON 文件备份**：一键导出与载入 `.json` 结构化文件，旧存档自动安全热迁移。

### 15. 🔁 一键「延续上回合」日程与自适应降级 (Schedule Reuse & Fallback)
- **日程记忆复用**：一键秒级排满上一回合 6 项日程安排，杜绝繁琐重复手动选课；
- **智能自适应降级**：当行动力或零花钱不足以支撑上回合高耗活动时，智能平滑回退至低耗替代方案。

### 16. 🧠 脑洞探索 HUD 深度探照看板 (Brain Cave HUD)
- **深层神经突触探照**：实时直观呈现当前脑洞层级深度与层级收益乘数；
- **竹管流光进度条与智能禁用**：动态感知行动力阈值，不足 15 点时智能蒙版防护并高亮预警。

### 17. 🎓 大学深造、大厂实习与时代风口中年抉择 (Higher Education & Late Life)
- **大学学术攻坚与实习**：新增考研论文文献精读、导师实验室攻坚、秋招群面模拟、创客路演与头部大厂技术实习；
- **时代浪潮重大抉择**：移动互联网风口、自媒体短视频爆款、重点学区房置业攻坚、行业周期洗牌与父母体检深谈。

### 18. 📢 版本更新公告与刷新自愈弹窗 (Changelog & What's New)
- **代码提交刷新即知**：开发者提交新版本后，玩家刷新页面系统自动优雅弹出新版本玩法介绍；

## 🛠️ 本地运行与开发 (Local Development)

本项目为**纯静态项目，零第三方打包编译流程**，克隆后开箱即用：

### 1. 快速克隆
```bash
git clone https://github.com/hufengxiao/chinese-parent.git
cd chinese-parent
```

### 2. 本地预览运行
直接使用任何静态 HTTP 服务器打开项目根目录：

```bash
# 方式 A：使用 npx serve (推荐)
npm start

# 方式 B：使用 Python 内置服务
python -m http.server 8080

# 方式 C：直接在浏览器双击打开 index.html
```

在浏览器访问 `http://localhost:8080/` 或对应提示地址即可。
